# Cars Dealership Web Application

## Introduction
This project is a full-stack web application developed for a national car retailer in the United States. It allows users to browse car dealerships, view detailed information about each branch, and read or submit customer reviews.

The application is built using modern web technologies including React for the frontend and Django, Flask, and Node.js for the backend. It follows a microservices architecture and integrates sentiment analysis to evaluate user reviews.

The project also demonstrates deployment using Docker, Kubernetes, and IBM Cloud Code Engine, along with CI/CD automation using GitHub Actions.
